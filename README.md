# MAGICAL reproduction

Reproduction and robustness test of MAGICAL (a PPI-network classifier for synthetic lethal / synthetic viable gene pairs), built on the official code and data.

- Paper: https://journals.plos.org/ploscompbiol/article?id=10.1371%2Fjournal.pcbi.1012336
- Code: https://github.com/Anubhagithub/MAGICAL
- Database: http://sls.uohyd.ac.in/new/magicaldb
- Website: https://harshini-suresha.github.io/magical-repro/

## What is here
- `site/` project website (open `site/index.html` in a browser; no build step). `site/results.js` carries the numbers and is generated by `src/build_site.py`.
- `figures/` 100 SVG figures with `figures/INDEX.tsv` listing source and caption. Figures 1-39 are computed and 40-59 simulated on a made-up 14-gene toy network, 60-79 are concept drawings, and 80-100 show the real results from `results/`.
- `src/` the pipeline:
  - `network_io.py`, `features_extract.py`, `verify_network.py` - rebuild the PPI network from the BioGRID edge list and re-extract features with python-igraph
  - `exp_reproduction.py` - published split, 10 seeds, shipped and re-extracted features -> `results/reproduction.json`
  - `exp_baselines.py` - RF / logistic regression / gradient boosting / network-only stumps, plus random-pair, gene-held-out and source-held-out splits -> `results/baselines.json`, `results/splits.json`
  - `exp_perturb.py` - node removal, edge removal, noise edges, degree-preserving rewiring, and candidate-pair scan -> `results/perturbation.json`, `results/candidates.json` (features cached in `results/perturb_parts/` so reruns resume)
  - `build_site.py`, `make_figures.py` - regenerate `site/results.js` and figures 80-100
- `data/official/` the official pair tables and the BioGRID edge list
- `results/` experiment outputs (JSON)

## Headline numbers
- Reproduction: 80.9% accuracy on seed 0 against the paper's ~81% (mean 80.87% +/- 0.44 over 10 seeds); 73.4% with only the 3 features that are reproducible from the public data.
- Baselines: an RF on all 20 shipped columns reaches 87.5%, gradient boosting 77.2%, logistic regression 56.6%; degree-product stump 48.5%, shortest-path stump 55.5%.
- Stricter splits: MCC 0.690 on random pairs, 0.503 holding out genes, 0.296 holding out the label source.
- Perturbations: macro-F1 falls 0.706 -> 0.517 when 30% of genes are removed and 0.706 -> 0.526 with 30% of edges removed; degree-preserving rewiring collapses it to ~0.40, so predictions depend on the exact wiring.
- Candidate pairs: 451 pairs are predicted confidently and consistently across network variants out of 6,535 unlabeled not-in-pool pairs; 289 are human-human (the official network file mixes species, so `src/annotate_candidates.py` adds symbols and species to `results/candidates_annotated.csv`, also published as `site/candidates.csv`).

## Run
1. `python -m venv .venv && source .venv/bin/activate`
2. `pip install -r requirements.txt`
3. `python src/exp_reproduction.py && python src/exp_baselines.py && python src/exp_perturb.py`
4. `python src/build_site.py && python src/make_figures.py`
